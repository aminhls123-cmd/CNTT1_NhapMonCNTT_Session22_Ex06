# Bài 6 : Ứng dụng AI trong khắc phục lỗi Git Permission Denied

## 1. Prompt 3 thành phần hỏi AI
- Bối cảnh: Đẩy code lên GitHub bằng Terminal bị lỗi quyền truy cập.
- Vấn đề: Terminal báo lỗi error: open(.git/FETCH_HEAD): Permission denied.
- Kỳ vọng: Giải thích nguyên nhân và hướng dẫn cách khắc phục.

## 2. Hướng dẫn sửa bằng quyền Administrator
- Mở lại Terminal với quyền Run as Administrator.
- Chạy lại lệnh push code và chụp ảnh màn hình minh họa.

## 3. Mẫu Bug Reporting gửi giảng viên
- Context: Dùng Windows, đã thử chạy quyền Admin nhưng không thành công.
- Expected: Lệnh git push thành công.
- Actual: Vẫn báo lỗi Permission denied.
- Log: Dán đoạn log lỗi từ Terminal.
